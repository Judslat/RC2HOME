# RC2HOME

### Custom Android Home Launcher for the DJI RC 2 Controller

**RC2HOME by FlyMyPhantom**

A lightweight custom Android launcher designed for the DJI RC 2 controller, allowing users to access installed Android applications while retaining access to DJI Fly.

Developed and tested on the stock DJI RC 2 firmware.

---

## Features

| Feature | Description |
|---|---|
| Custom Home Screen | Replaces the default Android HOME launcher |
| DJI Fly Integration | Launch DJI Fly directly from RC2HOME |
| All Apps | Browse and launch installed Android applications |
| Custom Wallpapers | Choose different backgrounds for the Home and All Apps screens |
| Swipe Navigation | Return to RC2HOME from the DJI Fly homepage |
| Accessibility Service | Provides custom swipe detection |
| Hide Apps | Hide unwanted apps and restore them later |
| DJI Fly Compatibility | Supports `dji.go.v5` and `dji.go.v6` |

## Installation

RC2HOME has been tested on the DJI RC 2 using a compatible Android PackageInstaller.

1. Download the RC2HOME APK and the required installation utilities.
2. Transfer the installation files to the controller.
3. Install the compatible PackageInstaller if required.
4. Install RC2HOME.
5. Select RC2HOME as the default HOME launcher.
6. Enable the RC2HOME Accessibility Service in Android settings.
7. Restart the controller and verify that RC2HOME launches correctly.

Installation procedures may vary depending on the controller's firmware.

## Navigation

**DJI Fly homepage:** Swipe left from the top-right gesture area to return to RC2HOME.

**DJI Fly camera:** DJI Fly's native navigation remains available.

The gesture area is deliberately small to avoid interfering with application menus.
